# Chat Chase
Browser game for desktop Chrome, built from supplied SPEC.md. Streamers run, jump and squat using a webcam; Twitch viewers send capped obstacles and race as ghosts. Demo and keyboard modes let anyone try it locally. No backend, secrets, payments or database.
## Platform
Web, desktop Chrome, OBS Window Capture at 1920×1080.
## Assumptions
User requested autonomous completion while asleep. Visual direction is inferred: a midnight running track, warm orange action color, ice-white typography, mint safety indicators. All product behavior comes from the supplied specification. No physical accuracy or real-channel testing is claimed without user hardware/account.
